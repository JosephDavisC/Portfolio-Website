# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)

## [1.0.0] - 2025-01-17

### Added
- Initial release of portfolio website
- Responsive layout optimized for mobile, tablet, and desktop
- Modern interface built with React, TypeScript, and Tailwind CSS
- Smooth motion effects using Framer Motion
- Professional dark theme with vibrant gradient accents
- Blog section with two articles:
  - BC Hacks 2024 article
  - My Journey: From Jakarta to UW article
- Portfolio section showcasing four projects:
  - IShowStream
  - JAM AI
  - Coffee Shop
  - Dino Marine VR
- About section with personal introduction
- Milestones section highlighting key achievements
- Credentials section
- Tennis & Coffee section
- Contact section
- SEO optimization with React Helmet
- Static meta tag generation for social media previews
- Open Graph and Twitter Card support
- Client-side routing with React Router
- Optimized image loading and performance

### Technical
- React 18 with TypeScript
- Tailwind CSS for styling
- Framer Motion for animations
- React Router for navigation
- Vite as build tool
